# Manage chats with AIRO

AIRO saves your chats so you can return to them later. You can rename or delete a chat, or copy its conversation ID.

## View previous chats

You can view recent chats from the AIRO chat panel or the sidebar.

**Chat panel**

Select **Chat history** in the header of the AIRO chat panel.

![Chat history in the AIRO chat panel](/assets/chat-history-button.CGhbMOyX.png)_Chat history in the AIRO chat panel_

**Sidebar**

Select **AIRO** in the sidebar.

![AIRO in the sidebar](/assets/view-previous-chats.Bske1Zod.png)_AIRO in the sidebar_

Select a chat in either list to open it.

Select **View all chats** below either list to open **All chats**. You can also open **All chats** by expanding AIRO to full screen. **All chats** groups chats by date.

Select the **...** menu next to a chat in **All chats** or in the header of an open chat to manage it.

## Rename a chat

AIRO uses your first message to name each chat. You can change the name at any time.

Complete the following steps to rename a chat:

1. Select the **...** menu.
   
2. Select **Rename**.
   
   ![Rename chat](/assets/rename-chat.DGfZGpK2.png)_Rename chat_
   
3. Enter a new name and select ✓ to save it.
   
   ![Save the new chat name](/assets/rename-chat-field.Ckm36qME.png)_Save the new chat name_
   

You can also rename an open chat by selecting its name in the chat header.

## Copy a conversation ID

Complete the following steps to copy a conversation ID:

1. Select the **...** menu.
   
2. Select **Copy conversation ID**.
   
   ![Copy conversation ID](/assets/copy-conversation-id.Dp-rk_Nb.png)_Copy conversation ID_
   

Include the conversation ID in a [support ticket](/en/airo/chat#support-tickets-in-chat) to identify the chat.

## Delete a chat

Complete the following steps to delete a chat:

1. Select the **...** menu.
   
2. Select **Delete**.
   
   ![Delete chat](/assets/delete-chat.C7XB67_8.png)_Delete chat_
   
3. Select **Delete** again to confirm.
