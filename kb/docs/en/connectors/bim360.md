# BIM 360

[BIM 360](https://www.autodesk.com/bim-360/) is a unified platform that connects teams and data in real-time to support informed decision making in industries from design to construction.

## API version

The BIM 360 connector uses the [Autodesk Forge API v2](https://aps.autodesk.com/en/docs/bim360/v1/reference/http/).

## How to connect to BIM 360 on Workato

The BIM 360 connector uses OAuth 2.0 to connect to BIM 360. We recommend that you assign an integration user to Workato for recipes and provision the user in the required accounts, hubs, and projects.

Complete the following steps to connect to BIM 360 in Workato:

1. [Authorize Workato in the BIM 360 Hub](#authorize-workato-in-the-bim-360-hub)
2. [Complete setup in Workato](#complete-setup-in-workato)

### Authorize Workato in the BIM 360 Hub

You must authorize Workato in the BIM 360 Hub before you can connect to BIM 360 on Workato.

> **BIM 360 ADMIN REQUIRED**
> 
> A BIM 360 account administrator is required to authorize an app in the BIM 360 Hub.

Complete the following steps to authorize Workato in the BIM 360 Hub:

1. Go to the **Account Admin** page in BIM 360.
   
   ![Account admin navigation](/assets/account-admin.eT_GeXuc.png)
   
2. Go to the **Apps** tab.
   
   ![Apps tab](/assets/app-page.CRHbigza.png)
   
3. Select **Autodesk Construction Cloud Connect** from the list of apps.
   
   ![Workato App](/assets/workato-app.BoFEDKqP.png)
   
4. Click **Add to BIM 360**. The authorization dialog appears.
   
   ![Authorization](/assets/authorise.CCcnfJlS.png)
   
5. Click **Authorize**. Workato appears as **Active** in BIM 360 Hub.
   
   ![Modal popup.](/assets/authorise-modal.PMq3gADX.png)
   

### Complete setup in Workato

Complete the following steps to set up the BIM 360 connection in Workato:

1. Enter a **Connection name** that identifies which BIM 360 instance Workato is connected to.
   
2. Expand **Advanced settings** and enter the **Client ID** and **Client secret** for your BIM 360 integration. Refer to BIM 360's [Manage API Access to BIM 360 Services](https://aps.autodesk.com/en/docs/bim360/v1/tutorials/getting-started/manage-access-to-docs/) guide to generate these credentials.
   
3. Optional. Use the **Requested permissions (OAuth scopes)** drop-down menu to select the permissions for Workato.
   
   By default, Workato requests all permissions and includes the required `user-profile:read` scope.
   
   You can select from the following scopes:
   
   - `user:read`
   - `account:read`
   - `data:write`
   - `data:read`
   - `data:create`
   - `account:write`
4. Click **Connect** to complete the setup. ![BIM 360 Connect](/assets/bim360-connect.BYLMW751.png)_Complete the connection fields and click **Connect**_

# BIM 360 - New or updated document in a project folder trigger

The **New or updated document in a project folder** trigger monitors a BIM 360 project folder you specify for newly created or updated documents.

## Input

| Input fields | Description |
| --- | --- |
| Hub name | Select the hub that contains the project you plan to monitor. |
| Project name | Select the project that contains the folder you plan to monitor. |
| Folder | Select the folder you plan to monitor. |
| When first started, this recipe should pick up events from | Set the date and time to start capturing trigger events. This enables your recipe to capture past events. Refer to [Triggers](/en/recipes/triggers#since-from) to learn more about this input field. |

## Output

| Output fields | Description |
| --- | --- |
| Hub ID | The BIM 360 ID of the hub that contains the document. |
| Project ID | The BIM 360 ID of the project that contains the document. |
| Folder ID | The BIM 360 ID of the folder that contains the document. |
| Item ID | The BIM 360 ID of the document. |
| Item type | The document's type. |
| Attributes | Contains information about the document's attributes, such as their `Name` an `Created at` date. |
| Links | Contains information about the document's link, such as its `Href`. |
| Relationships | Contains information about the document's relationships, such as their `Versions` and `Links`. |

# BIM 360 - New or updated issue (V2) in a project trigger

The **New or updated issue (V2) in a project** trigger monitors a BIM 360 project folder you specify for newly created or updated issues.

## Input

| Input fields | Description |
| --- | --- |
| Hub name | Select the hub that contains the project you plan to monitor. |
| Project name | Select the project you plan to monitor. |
| When first started, this recipe should pick up events from | Set the date and time to start capturing trigger events. This enables your recipe to capture past events. Refer to [Triggers](/en/recipes/triggers#since-from) to learn more about this input field. |

## Output

| Output fields | Description |
| --- | --- |
| Hub ID | The BIM 360 ID of the hub that contains the issue. |
| Project ID | The BIM 360 ID of the project that contains the issue. |
| ID | The BIM 360 ID of the issue. |
| Container ID | The BIM 360 ID of the container that contains the issue. |
| Display ID | A chronological and user-friendly ID for the issue. |
| Title | The issue's title. |
| Description | The issue's description. |
| Snapshot URN | The unique resource name (URN) for the snapshot associated with the issue. |
| Issue type ID | The BIM 360 ID of the issue type. |
| Issue subtype ID | The BIM 360 ID of the issue subtype. |
| Assigned to | The BIM 360 ID of the user, company, or role associated with the issue's current assignee. |
| Due date | The issue's due date. |
| Location ID | The issue's location breakdown structure (LBS) ID. |
| Location details | The issue's location in plain text. |
| Owner ID | The BIM 360 ID of the issue's owner. |
| Root cause ID | The BIM 360 ID of the issue's root cause type. |
| Issue template ID | The BIM 360 ID of the template used to create the issue. |
| Comment count | The number of comments on the issue. |
| Attachment count | The number of attachments on the issue. |
| Opened by | The BIM 360 ID of the user who opened the issue. |
| Opened at | A timestamp indicating when the issue was opened. |
| Closed by | The BIM 360 ID of the user who closed the issue. |
| Closed at | A timestamp indicating when the issue was closed. |
| Created by | The BIM 360 ID of the user who created the issue. |
| Created at | A timestamp indicating when the issue was created. |
| Updated by | The BIM 360 ID of the user who last updated the issue. |
| Updated at | A timestamp indicating when the issue was last updated. |
| Client created at | A timestamp indicating when the issue was created in the client's system. |
| Client updated at | A timestamp indicating when the issue was last updated in the client's system. |
| Status | The issue's current status, such as `draft`, `open`, or `closed`. |
| Assigned to type | Specifies whether `Assigned to` is a user, company, or role. |
| Permitted statuses | The statuses permitted for the issue. |
| Permitted attributes | The attributes permitted for the issue. |
| Permitted actions | The actions permitted for the issue. |
| Linked documents | Contains information about documents related to the issue, such as their `Type`, `Details`, and `Created at` date. |
| Official response | Contains information about the response to the issue, such as its `Responded at` date and `Response`. |
| Custom attributes | Contains information about the issue's custom attributes, such as their `Type`, `Title`, and `Attribute definition ID` . |
| Links | Contains information about the issue's associated links, such as their `Type` and `Data`. |

# BIM 360 - Export drawing in a project action

The **Export drawing in a project** action exports a page from a PDF in BIM 360's document management system as a new PDF file.

> **LIMITATIONS**
> 
> The **Export drawing in a project** action can only export documents from the `Plans` folder and its sub-folders. Refer to BIM 360's [Plans and Project Files](https://help.autodesk.com/view/BIM360D/ENU/?guid=GUID-9B58CB2C-0519-47B0-9199-4535577B594A) guide for more information.

## Input

| Input fields | Description |
| --- | --- |
| Hub name | Select the hub that contains the document you plan to export a page from. |
| Project name | Select the project that contains the document you plan to export a page from. |
| Folder name | Select the folder that contains the document you plan to export a page from. |
| File name | Select the file that contains the document you plan to export a page from. |
| Version number | Select the document's version number. |
| Include markups | Specify whether to export the page's annotations. |
| Include hyperlinks | Specify whether to export the page's hyperlinks. |

## Output

| Output fields | Description |
| --- | --- |
| Hub ID | The BIM 360 ID of the hub that contains the page. |
| Project ID | The BIM 360 ID of the project that contains the page. |
| Folder ID | The BIM 360 ID of the folder that contains the page. |
| Item ID | The BIM 360 ID of the page. |
| Status | The status of the export job in BIM 360. |
