# Clay - Get company profile action

The **Get company profile** action retrieves details about a company in Clay, such as its industry, size, and location.

## Input

| Input field | Description |
| --- | --- |
| Company identifier | Enter the domain, such as `stripe.com`, or the LinkedIn URL of the company. The action doesn't accept company names. |

## Output

The following are a representative set of output fields. Refer to the output datapills in the recipe editor to view the remaining fields.

| Output field | Description |
| --- | --- |
| Name | The name of the company. |
| Description | The description of the company. |
| Company type | The type of the company. |
| Company size | The employee count range of the company. |
| Domain | The domain of the company. |
| LinkedIn URL | The LinkedIn URL of the company. |
| Location | The location of the company. |
| Industry | The industry of the company. |
| Annual revenue | The annual revenue range of the company. |
| Total funding amount range (USD) | The total funding amount range of the company, in USD. |
