# SAP Concur - Upload receipt image action

The **Upload receipt image** action uploads a receipt image to SAP Concur.

## Input

| Input field | Description |
| --- | --- |
| Receipt image url | Enter the receipt image URL to upload. |
| Image format | Select the image format. Supported formats include: image/jpeg, image/jpg, image/png, application/pdf |

## Output

| Output field | Description |
| --- | --- |
| Receipt ID | The unique identifier for the uploaded receipt image. |
| Receipt URI | The URI to the uploaded receipt image. |
