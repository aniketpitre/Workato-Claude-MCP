# Cornerstone HR - Search records action

The **Search records** action searches for records that match your criteria in a Cornerstone HR object you select.

## Input

Input fields dynamically generate based on the object you select. The following field is common to all objects. Refer to the [Cornerstone API documentation](https://apiexplorer.csod.com) for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to search. Options include **User**, **Transcript**, **Session**, **Goal**, **Job requisition**, **Job applicant**, and other Cornerstone HR objects related to training, certification, and recruiting. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [Cornerstone API documentation](https://apiexplorer.csod.com) for a complete list of output fields.

# Cornerstone HR - Get record details by ID action

The **Get record details by ID** action retrieves the details of a record, such as a user, by its ID in Cornerstone HR.

## Input

Input fields dynamically generate based on the object you select. The following field is common to all objects. Refer to the [Cornerstone API documentation](https://apiexplorer.csod.com) for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to retrieve. Options are **User** and **LO**. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [Cornerstone API documentation](https://apiexplorer.csod.com) for a complete list of output fields.
