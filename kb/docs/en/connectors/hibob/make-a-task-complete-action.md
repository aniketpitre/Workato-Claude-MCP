# HiBob - Make a task complete action

The **Make a task complete** action marks a task as completed in HiBob.

## Input

| Input field | Description |
| --- | --- |
| Task ID | Provide the ID of the task to be updated. |

## Output

| Output field | Description |
| --- | --- |
| To dos updated | Returns the number of tasks updated. |
