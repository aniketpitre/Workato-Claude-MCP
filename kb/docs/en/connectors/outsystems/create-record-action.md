# OutSystems - Create record action

The Create record action creates a record in the OutSystems module you select.

![Create record action](/assets/create-record-action.u9Gdtcb_.png)_Create record action_

## Input

| Input field | Description |
| --- | --- |
| Module | Select the module in which you plan to create a record. |
| Entity ID | Select the entity ID of the module in which you plan to create a record. |
| Label | Enter the label you plan to add to the record. |

## Output

| Output field | Description |
| --- | --- |
| Record | This entry contains information specific to the record attributes and other configurations, such as `UPLOADDATETIME` or record ID, you selected for the OutSystems object. |

# OutSystems - Create record batch action

The Create record batch action creates records in the OutSystems module you select.

![Create records batch action](/assets/create-records-batch-action.xSBHHOQT.png)_Create records batch action_

## Input

| Input field | Description |
| --- | --- |
| Module | Select the module in which you plan to create records. |
| Entity ID | Select the entity ID of the module in which you plan to create records. |

## Output

| Output field | Description |
| --- | --- |
| Entity | The entity ID you selected for the action. |
| Number of records | The number of records created for the batch action. |
