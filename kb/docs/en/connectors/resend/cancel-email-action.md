# Resend - Cancel email action

The **Cancel email** action cancels a scheduled email in Resend before it's delivered.

## Input

| Input field | Description |
| --- | --- |
| Email ID | Enter the unique ID of the scheduled email to cancel. |

## Output

| Output field | Description |
| --- | --- |
| Object | The type of object canceled. For example, `email`. |
| Email ID | The unique ID of the canceled email. |
