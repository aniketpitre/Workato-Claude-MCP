# Resend - Update record action

The **Update record** action changes the send time of a scheduled email in Resend.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the type of record to update. **Scheduled email** is the only option. |
| Email ID | Enter the unique ID of the scheduled email to update. |
| Scheduled at | Select the new date and time to send the email. |

## Output

| Output field | Description |
| --- | --- |
| Object | The type of record updated. For example, `email`. |
| Email ID | The unique ID of the updated email. |
