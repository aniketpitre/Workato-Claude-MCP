# Spryng - Cancel message action

The **Cancel message** action cancels a message in Spryng.

## Input

| Input fields | Description |
| --- | --- |
| Message ID | Enter the ID of the message to cancel. |

## Output

| Output fields | Description |
| --- | --- |
| Success | A boolean response indicating if the cancel message action was successful. |
