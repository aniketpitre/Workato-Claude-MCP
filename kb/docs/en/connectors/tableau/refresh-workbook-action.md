# Tableau - Refresh workbook action

The **Refresh workbook** action refreshes a workbook you specify.

## Input

| Input field | Description |
| --- | --- |
| Workbook ID | Provide the unique ID of workbook to refresh. |

## Output

| Output field | Description |
| --- | --- |
| Notes | Additional information or comments related to the workbook. |
| Workbook ID | The unique identifier for the workbook. |
| Name | The name of the workbook. |
| Refresh ID | The unique identifier for the refresh process associated with the workbook. |
| Mode | The mode of the workbook. |
| Type | The type of workbook operation. |
| Progress | The progress of an operation on the workbook, typically represented as a percentage or status. |
| Created at | A timestamp indicating when the workbook was created. |
| Started at | A timestamp marking the start time of a workbook operation. |
| Completed at | A timestamp marking the completion time of a workbook operation. |
| Finish code | A number or status code representing the outcome of a workbook operation. |

# Tableau - Run extract refresh task action

The **Run extract refresh task** action runs an extract refresh task in Tableau.

## Input

| Input field | Description |
| --- | --- |
| Task ID | Provide the unique ID of the task you plan to refresh. |

## Output

| Output field | Description |
| --- | --- |
| Workbook ID | The unique identifier for the workbook. |
| Name | The name of the workbook. |
| Extract refresh job ID | The unique identifier for the refresh process associated with the workbook. |
| Mode | The mode of the workbook refresh job. |
| Type | The type of workbook. |
| Progress | The progress of an operation on the workbook, typically represented as a percentage or status. |
| Created at | A timestamp indicating when the workbook refresh job was created. |
