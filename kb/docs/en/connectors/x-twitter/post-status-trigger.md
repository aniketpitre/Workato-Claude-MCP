# X - Post status trigger

The **Post status** trigger posts a status in X.

## Input

| Input field | Description |
| --- | --- |
| Message | Enter the message content. |

## Output

| Output field | Description |
| --- | --- |
| Edit history Tweet IDs | The edit history tweet IDs. |
| ID | The post ID. |
| Text | The message text. |
