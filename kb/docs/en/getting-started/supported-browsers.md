# Supported browsers

Workato is supported on all modern and up-to-date browsers, including, but not limited to:

- Google Chrome
- Apple Safari
- Microsoft Edge
- Mozilla Firefox

> **INTERNET EXPLORER**
> 
> Workato no longer supports the Internet Explorer browser. If you are currently using Internet Explorer, we recommend switching to Microsoft Edge or Google Chrome for optimal performance and compatibility.
