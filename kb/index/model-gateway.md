# Model Gateway

11 pages. Paths are relative to the repository root.


## Model Gateway

- **Model Gateway** - `kb/docs/en/ai-gateway.md` - Model Gateway gives you OpenAI-compatible and Anthropic-compatible APIs to authenticate LLM providers, route requests, and enforce policies across your applications.
- **Configure Model Gateway** - `kb/docs/en/ai-gateway/configure.md` - Set up Model Gateway by adding providers, creating routes, issuing access keys, and defining policies that control rate limits, token limits, and IP access.
- **Connect clients to Model Gateway** - `kb/docs/en/ai-gateway/connect-clients.md` - Configure Claude Desktop, Claude Code, and the Anthropic Python and TypeScript SDKs to send requests through Model Gateway.
- **Model Gateway dashboard** - `kb/docs/en/ai-gateway/monitor.md` - Use the Model Gateway dashboard to monitor request volume, token usage, and success rates across your workspace.
- **Test a Model Gateway route** - `kb/docs/en/ai-gateway/test-route.md` - Send a test request to Model Gateway through the OpenAI-compatible or Anthropic-compatible API to confirm a route works.

## Configure Model Gateway

- **Model Gateway access keys** - `kb/docs/en/ai-gateway/access-keys.md` - Create, edit, refresh, and delete the access keys applications use to authenticate with Model Gateway.
- **Connect Fireworks AI to Model Gateway** - `kb/docs/en/ai-gateway/fireworks.md` - Use your own Fireworks AI API key with Model Gateway to route requests to open-weight models hosted on Fireworks AI.
- **Model Gateway policies** - `kb/docs/en/ai-gateway/policies.md` - Create Model Gateway policies that apply rate limits, token limits, and IP access restrictions to routes and access keys.
- **Model Gateway providers** - `kb/docs/en/ai-gateway/providers.md` - Add, edit, and delete the LLM provider connections Model Gateway uses to authenticate with Anthropic, OpenAI, OpenAI Compatible, Azure OpenAI, AWS Bedrock, AWS Bedrock Mantle, Fireworks, and Gemini.
- **Route builder** - `kb/docs/en/ai-gateway/route-builder.md` - Use the route builder to define rules that route LLM requests to a specific provider and model based on tags, keys, parameters, or complexity.
- **Model Gateway routes** - `kb/docs/en/ai-gateway/routes.md` - Create, edit, and delete the Model Gateway routes that determine which provider and model serves each request.
